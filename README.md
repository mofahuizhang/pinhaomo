# 拼好模主篇 · 副篇

多主体模块生态的制度总览，及附于其后的赛道测算与健康守护一例。2026-10-20 定稿。

| 件 | 书名 | 副题 | 汉字 | 页 |
|---|---|---|---:|---:|
| 主篇 | 拼好模主篇 | 通典 | 22,012 | 36 |
| 副篇 | 拼好模副篇 | 别录 | 10,438 | 20 |

两件是母子，不是并列：副篇为「主篇之别录」，与主篇同行。主篇立制度，副篇算生计——把「谁做什么、靠什么吃饭、门槛几何」逐条摆出，再以健康守护模块示一个模块如何从数据长成服务。

> 首发存档：Zenodo（2026-10-19）｜DOI [10.5281/zenodo.23478241](https://doi.org/10.5281/zenodo.23478241)

## 主篇讲什么

九典：建制（从 1+N 到拼好模）／分层（生态架构）／分职（分工与赛道）／通变（动力学与病理学）／宪治（治理分层与生态宪法）／验效（落地与验证）／事例（垂直案例）／通联（接口）／界限（本书不宣称什么）。

核心是五项条件：N 可插拔、N 开放给外部、标准接口、多主体模块市场、治理与商业闭环。五条全备方成拼好模，缺其一仍为单主体。这条门槛把「生态」从泛称改成可判定之物。

## 副篇讲什么

上篇赛道十节，按挣钱方式而非技术门类分组；下篇健康守护七节，记一个伴生模块的完整形态。测算一律标量级、不标确数，明言「非预测、非承诺」。

## 与他三件的关系

| 简称 | 书名 | 关系 |
|---|---|---|
| 《架构》 | 内核旋钮架构 | 单主体内部架构，主篇不论 |
| 《协议》 | MCP 控制层协议规范 | 模块互连与控制，主篇只引编号 |
| 《园丁》 | 园丁计划 | 生态随时间的演化，主篇只引编号 |

引用纪律四条：上游只声明接口，不定义下游内容；下游只引用编号，不复制上游定义；术语有歧义时以项目层术语表为准；跨项目的新机制先回归属项目立规，再于下游引用。

所以本仓库不追求「单篇自足」——那会立刻产生两份定义，日后一改就漂移。解法是让邻居同时可得，故五件宜同批出。

## 关于书名

现名《拼好模主篇》《拼好模副篇》，是为过著作权登记取的短名——江苏登记要求标题不超过 36 个非特殊字符，短名便于填报与辨认。

原名为《拼好模生态与产业蓝图》与《拼好模 别册·赛道测算与健康守护模块》。二名较长，登记不便，暂以「主篇／副篇」代之。

**登记既毕，书名与仓库显示名皆可改回原名。** 正文自始至终只称「主篇」「副篇」，不依赖书名，故改回只需动三处：一级标题、页脚署名行、书目表，条文一字不改。
